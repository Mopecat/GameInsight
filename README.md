# GameInsight

GameInsight 是一个面向手游出海业务的前端 BI 分析平台，用于模拟游戏公司内部数据中台中的核心分析场景。项目覆盖运营、增长、数据分析团队常用的实时监控、留存分析、转化漏斗、用户路径追踪和配置化看板搭建能力。

## 项目定位

一句话介绍：

面向手游出海业务的数据中台 BI 分析平台，支持实时运营看板、留存分析、漏斗分析、用户路径分析和配置化图表搭建。

核心能力：

- 核心业务围绕国家、平台、渠道、版本等维度展开。
- 核心事件覆盖安装、注册、教程完成、战斗开始、商店浏览、抽卡、付费等典型手游链路。
- 技术侧重点包括 TypeScript 类型建模、可复用图表组件、Web Worker 聚合、虚拟列表和配置化 schema。

## 第一阶段范围

- 搭建 React + TypeScript + Vite 项目基础。
- 实现 BI 风格的应用主框架。
- 提供五个工作区入口：实时看板、留存分析、漏斗分析、用户路径、配置看板。
- 提供国家、平台、渠道、版本四个全局筛选条件。
- 使用 Zustand 管理共享筛选状态。
- 使用 Vitest + Testing Library 做应用壳冒烟测试。

## 数据模型

当前项目已经内置手游出海业务 mock 数据生成器。生成器不是简单随机数，而是围绕玩家生命周期、市场差异和渠道质量构造事件流。

核心维度：

- 国家：美国、日本、韩国、巴西、德国、泰国。
- 平台：iOS、Android。
- 渠道：Facebook、Google、TikTok、自然量。
- 版本：1.0.0、1.1.0、1.2.0。

核心事件：

- `install`：安装。
- `register`：注册。
- `tutorial_complete`：教程完成。
- `battle_start`：战斗开始。
- `shop_view`：商店浏览。
- `gacha`：抽卡。
- `payment`：付费。

生成规则：

- 使用 seed 保证同一配置下数据可复现，方便调试和演示。
- 不同国家拥有不同的注册率、留存率、付费率和 ARPPU。
- 不同渠道拥有不同的获客成本、注册质量和付费倾向。
- 玩家会被划分为非付费、小额付费、中额付费和高额付费分层。
- 事件按玩家时间线生成，保证安装、注册、教程、战斗、商店、抽卡、付费等链路顺序合理。

## 后续开发阶段

1. 可复用图表组件：封装 ECharts 基座、指标卡、趋势图、热力图、漏斗图。
2. 实时运营看板：实现实时数据更新、多维筛选和图表联动。
3. 留存分析：使用 Web Worker 聚合留存数据，并用虚拟列表承载大规模同期群明细。
4. 漏斗分析：实现从安装到首充的转化漏斗与分组对比。
5. 用户路径分析：使用 AntV G6 展示事件转移图。
6. 配置化看板：基于 schema 实现轻量自助 BI 配置能力。
